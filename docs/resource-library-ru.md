# Локальные библиотеки и готовые примеры

Каталог использует существующие работы авторов, а не сгенерированные макеты.
Названия карточек русские, содержание оригинальных примеров сохранено.
При наличии установленной библиотеки редактор показывает её вместо старой
галереи демонстрационных постеров. Пользовательские документы сохраняются.

В открытом пакете:

- **shadcn/ui:** Dashboard, Tasks, Playground — статические снимки настоящего
  DOM официальных [примеров](https://ui.shadcn.com/examples/dashboard).
  [Исходный проект](https://github.com/shadcn-ui/ui), MIT.
  Текст, фигуры и SVG-значки импортируются отдельными редактируемыми слоями.
- **IBM Carbon v11:** страницы Forms, Buttons, Data Table, Color Tokens
  из официального [Carbon Design Kit](https://github.com/carbon-design-system/carbon-design-kit).
  Это архивный Sketch kit v11.0.0, Apache-2.0. Его источник закреплён по SHA.

**Apple iOS 27 UI Kit** устанавливается отдельно и остаётся локально.
[Официальный источник](https://developer.apple.com/design/resources/)
и [Sketch-файл](https://www.sketch.com/s/04c24d8b-38fb-4afb-8836-36617e022f02).
Исходный архив и преобразованные материалы Apple не включаются в Git,
публичный пакет или релиз. Применяются условия Apple Design Resources.
Локальный импорт включает палитру, типографику, диалог и 36 исходных
текстовых вариантов кнопок. Координаты вариантов взяты со страницы автора.

Примеры приложений статические: импорт не переносит JavaScript, сервер,
прокрутку или действия кнопок. Прокручиваемые области становятся масками.
Sketch-импорт переносит геометрию, символы, текст, цвета и изображения;
это не полная реализация формата Sketch. Не поддерживаются все эффекты,
ограничения изменения размера и типографические возможности оригинала.
Для работы без установки дополнительных шрифтов импортированные копии
используют встроенные Inter и JetBrains Mono. Подстановки записаны в метаданных.
Оригинальные архивы не изменяются.

Формат пакета: `catalog.json` с `version: 1`, документами `.op` и JPEG-превью.
Идентификаторы начинаются с `library-`, пути — только локальные имена файлов.
Web-host загружает пакет через существующий сервер `/pkg/assets/resource-library/`.
Пакет не требует отдельной подписки, API или облачного хранилища.

Инструменты: `tools/import-sketch-resources.py`,
`tools/resource-snapshot.mjs`, `tools/normalize-resource-snapshot.py`.
Все превью получены отрисовкой импортированных документов в OpenPencil.
